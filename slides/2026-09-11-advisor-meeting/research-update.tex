\begin{frame}[t]
\frametitle{An RLM lets a language model use Python\\and ask smaller questions.}
A recursive language model (RLM) writes code to inspect its input, ask helpers, and combine their answers.\par
\vspace{2mm}
\centering
\begin{tikzpicture}[font=\small]
\node[card,text width=3.0cm] (data) at (0,0) {The full input stays\\in the workspace.};
\node[card,text width=3.3cm] (root) at (5,0) {The main model\\chooses the next step.};
\node[card,text width=3.0cm] (helpers) at (10,0) {Helper calls answer\\smaller questions.};
\node[card,text width=5.2cm] (result) at (5,-1.9) {Python combines the answers.\\The model inspects or finishes.};
\draw[flow,<->] (root) -- node[above]{inspect} (data);
\draw[flow] (root) -- node[above]{delegate} (helpers);
\draw[flow] (helpers.south) |- (result.east);
\draw[flow] (result.north) -- (root.south);
\end{tikzpicture}
\par\vspace{2mm}
\raggedright
The full input can be too large for one model call. A helper can divide its own task again.
\smallnote{Python runs the model's code. Our tests mostly use one layer of helper calls.\par
Concept: \href{https://alexzhang13.github.io/blog/2026/harness/}{Alex Zhang's blog} and \href{https://arxiv.org/abs/2512.24601}{Recursive Language Models}.}
\end{frame}

\begin{frame}[t]
\frametitle{We taught the main model what to do next,\\not just what answer to give.}
In supervised fine-tuning (SFT), demonstrations show what the model sees and what Python code it should write next.\par
\vspace{2mm}
\begin{columns}[T,onlytextwidth]
\begin{column}{0.48\textwidth}
\begin{block}{An example observation}
``Count users whose place-question weights total more than 5.''\par\medskip
The records are stored in a file the model can read.
\end{block}
\vspace{2mm}
\end{column}
\begin{column}{0.48\textwidth}
\begin{block}{What it learns to do}
Ask the helper which questions concern places.\par\medskip
Add their weights for each user.\par\medskip
Count totals above 5 and return the answer.
\end{block}
\end{column}
\end{columns}
\smallnote{Simplified example. Training used 72 demonstrations, repeated six times, including real helper replies and Python results. This teaches a routine, not open-ended planning.}
\end{frame}

\begin{frame}[t]
\frametitle{An answer can be right for the wrong record.}
We next tested the helper alone: does a passage support, contradict, or leave a statement unclear?\par
\vspace{2mm}
\begin{columns}[T,onlytextwidth]
\begin{column}{0.57\textwidth}
\begin{block}{A simple reading task}
Passage: ``Maya bought a red bike.''\par\medskip
Row 7: ``Maya bought a vehicle.''\par
The passage supports this statement.\par\medskip
Row 8: ``The bike is blue.''\par
The passage contradicts this statement.
\end{block}
\end{column}
\begin{column}{0.39\textwidth}
\begin{block}{Suppose row 7's answer is stamped ``row 8.''}
The model may answer for row 8 instead.\par\medskip
``Contradicted'' is then a sensible label---attached to the wrong statement.
\end{block}
\end{column}
\end{columns}
\vspace{1mm}
Accuracy was 39\% with wrong-row names and 80\% with names pointing to no row.
\smallnote{Simplified example of deliberately misleading names. Software fixed each answer's name; the model chose the label. The comparison used 16 batches of 48 questions. [H1]}
\end{frame}

\begin{frame}[t]
\frametitle{The next test is whether these gains\\help solve a complete problem.}
\begin{block}{Can the model combine familiar steps in a new way?}
The trained routine worked better on new records. We still need to test new combinations of calculations.
\end{block}
\vspace{1mm}
\begin{block}{Do better helper answers improve the final answer?}
We will change only the matching tags, keep the model and task fixed, and check the complete result.
\end{block}
\vspace{2mm}
Better individual answers are a starting point, not the final goal.
\smallnote{These are next tests, not established capabilities. Numbered batch prompts already exist; the contribution must go beyond ``numbering helps.''}
\end{frame}

We want to solve unfamiliar problems by combining familiar steps. Training and better tools may help the model learn how to choose those steps.
\smallnote{This is a research direction, not an achieved capability. The related rlm-bootstrap project supplies ideas for this learning loop. Future comparisons must separate improvements in the model from improvements in its tools.}
