\begin{frame}[t]
\frametitle{How can a model finish a multi-step task?}
A recursive language model (RLM) can use tools and ask helper models to solve parts of a task.
\begin{block}{For this study, we returned to a basic skill.}
Can a small model look up missing information and use it to finish a task?
\end{block}
\textbf{Example: Make a wooden pickaxe in a crafting game.}
\begin{enumerate}
\item The model asks which ingredients it needs.
\item It makes the parts and then the pickaxe.
\item The game checks whether the pickaxe actually exists.
\end{enumerate}
\aside{Simplified illustration of TextCraft, our test environment. These experiments use one model with tools, not recursive helper calls.}
\end{frame}

\begin{frame}[t]
\frametitle{We compared two kinds of worked examples.}
A program generated two kinds of worked examples. We trained copies of the same model to imitate their actions. This is \textbf{supervised fine-tuning}.
\vspace{3mm}
\begin{columns}[T,onlytextwidth]
\begin{column}{.48\textwidth}
\begin{block}{The teacher already knows the recipes.}
It chooses the route using that knowledge, then shows the steps.
\medskip

``Look up planks. Make planks. Continue along the planned route.''
\end{block}
\end{column}
\begin{column}{.48\textwidth}
\begin{block}{The teacher discovers the recipes.}
It chooses the route by looking up which parts are needed.
\medskip

``Look up the pickaxe. Discover its parts. Look up their recipes.''
\end{block}
\end{column}
\end{columns}
\vspace{2mm}
Both show recipe lookups. They differ in how the route is chosen.
\aside{Simplified examples, not literal training records. Both use the same 32 training tasks and 366 demonstrated steps. Their histories and amount of text differ.}
\end{frame}

\begin{frame}[t]
\frametitle{Letting code fill in recipe details helped.}
The model still chooses the item and amount. Code fills in ingredients from a recipe the model already looked up.\par
\vspace{2mm}
We used the discovery-trained models, with \textbf{no extra training}.\par
\vspace{1mm}

\textbf{Question:} Which decisions need a model, and which details should code handle?
