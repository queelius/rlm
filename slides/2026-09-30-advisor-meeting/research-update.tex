\begin{frame}[t]
\frametitle{Can a model learn useful steps for an unfamiliar task?}
A recursive language model (RLM) can use code and ask another model to handle a smaller task. A helper can, in turn, ask its own helper.
\vspace{4mm}

\medskip
\textbf{Today's focus:} Can we improve how a small model learns these steps by improving its worked examples?
\aside{Our longer-term aim is useful task decomposition. Today's strongest evidence concerns learning tool actions, not general recursive reasoning.}
\end{frame}

\begin{frame}[t]
\frametitle{What did we learn from reward training?}
Reinforcement learning (RL) rewards attempts that actually finish the task.
We started with an SFT-trained model and trained on eight crafting goals.

\begin{frame}[t]
\frametitle{Other datasets helped us ask what actually improved.}
\textbf{MuSiQue and HotpotQA ask questions about several documents.}
Our trained question-splitting system did not clearly beat answering directly, and used much more text.
\medskip

\textbf{AG News and DBpedia ask for a topic label.}
Small RL gains on news weakened on fresh examples and did not clearly transfer to encyclopedia entries.
\medskip

\textbf{MRCR asks for a particular earlier reply in a conversation.}
RL mostly improved exact reproduction of the answer, not finding the right reply.
\aside{These are different studies, not a shared leaderboard. A higher score does not by itself show better decomposition. The reading guide explains each test and its limits.}
\end{frame}

\begin{frame}[t]
\frametitle{Can the teaching repair survive stronger tests?}
\begin{block}{Research question}
Can rebuilding what the learner sees make existing worked examples more useful, without changing the actions we teach?
\end{block}
\vspace{1mm}
\textbf{Test new problems.} Use new recipe structures, not just more attempts at familiar goals.
\smallskip

\textbf{Use stronger comparisons.} Include a teacher that discovers recipes in order, and give the original examples more training.
\smallskip

\textbf{Find the limits.} Try another model and test whether the gain is mainly easier copying of item names.
\aside{A paper candidate, not an established general method. What evidence would make it useful beyond this game?}
\end{frame}
