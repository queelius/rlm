\begin{frame}[t]
\frametitle{When does breaking a problem into smaller tasks help?}
A recursive language model (RLM) can use code and ask another model for help. Our experiments tested different parts of that idea.
\medskip

\textbf{We supplied some splits ourselves.} Our code asked a separate helper to check each candidate against the requirements.
\medskip

\textbf{We also trained the model to choose smaller questions.} It proposed a plan for answering a question using several documents.
\medskip

\textbf{In crafting, we trained the model to choose its next action.} It looked up recipes and made the needed parts.
\aside{These are different abilities. We have not yet demonstrated a generally useful, learned tree of recursive helpers.}
\end{frame}

\begin{frame}[t]

Supervised fine-tuning (SFT) teaches the model to copy the next action in a worked example.

\end{block}
\end{column}
\begin{column}{.48\textwidth}
\begin{block}{Revised training example}
\small

\begin{frame}[t]
\frametitle{What did we learn from reward training?}
Reinforcement learning (RL) rewards attempts that actually finish the task.
We started with an SFT-trained model and trained on eight crafting goals.

\begin{frame}[t]
\frametitle{The broader tests changed how we interpret progress.}
\textbf{A programmed split helped select candidates that met stated requirements.}
Helpers checked one candidate at a time. The model did not learn to choose that split.
\medskip

\textbf{News-classification gains weakened on fresh examples.}
The AG News tests showed why repeating training is not enough: we also need new articles.
\medskip

\textbf{Conversation-retrieval RL mostly improved exact copying.}
In MRCR, the model reproduced earlier replies more accurately, but did not find the right reply more often.
\aside{These are separate studies. We now ask which ability changed, whether it helps the whole task, and whether it carries over to new problems.}
\end{frame}

\begin{frame}[t]
\frametitle{Can the teaching repair survive stronger tests?}
\begin{block}{Research question}
Can rebuilding what the learner sees make existing worked examples more useful, without changing the actions we teach?
\end{block}
\vspace{1mm}
\textbf{Test new problems.} Use new recipe structures, not just more attempts at familiar goals.
\smallskip

\textbf{Use stronger comparisons.} Include a teacher that discovers recipes in order, and give the original examples more training.
\smallskip

\textbf{Find the limits.} Try another model and test whether the gain is mainly easier copying of item names.
\aside{A paper candidate, not an established general method. What evidence would make it useful beyond this game?}
\end{frame}
