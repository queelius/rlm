% Slide 3 -------------------------------------------------------------------
\begin{frame}{What have we learned so far?}
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.43\textwidth}
      \begin{beamercolorbox}[wd=\linewidth,sep=.8em,rounded=true]{block body}
        \textbf{Promising small preliminary test}\par
        \vspace{0.45em}

        {\small Three comparison setups\hfill 0\%}\par
        {\color{RlmMuted!35}\rule{0.012\linewidth}{0.24cm}}\par
        \vspace{0.35em}

        {\small\textbf{Model trained for RLM work}\hfill\textbf{67\%}}\par
        {\color{RlmTeal}\rule{0.67\linewidth}{0.24cm}}\par

        \vspace{0.55em}
        {\scriptsize\color{RlmMuted}
          Six kinds of tasks; 36 attempts per setup. A success required a correct answer and a
          complete, valid record of the model's work.}
      \end{beamercolorbox}
    \end{column}

    \begin{column}{0.54\textwidth}
      \textbf{The larger training runs worked reliably}
      \begin{itemize}
        \item All \textbf{four carefully matched training runs} completed successfully.
        \item Each run took about \textbf{63 minutes}.
        \item Showing tasks in six different formats took about the same training time as using
          one standard format.
      \end{itemize}

      \vspace{0.2em}
      \textbf{A useful lesson about training from rewards}
      \begin{itemize}
        \item Four early attempts all received the same top score.
        \item With no difference between the scores, there was nothing to learn; a safety check
          stopped before the model was changed.
      \end{itemize}
    \end{column}
  \end{columns}

  \vspace{0.3cm}
  \begin{alertblock}{Important limitation}
    We have not yet tested the newest trained models on genuinely new tasks. These findings show
    that the approach is workable and promising---not that it has been proven to work broadly.
  \end{alertblock}
\end{frame}

\begin{frame}{What should we test next?}
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.48\textwidth}
      \begin{block}{Tasks and evidence}
        \begin{itemize}
          \item Which tasks truly require code and a workspace rather than memorized patterns?
          \item How much improvement on genuinely new tasks would be convincing?
        \end{itemize}
      \end{block}
    \end{column}
    \begin{column}{0.48\textwidth}
      \begin{block}{Research priorities}
        \begin{itemize}
          \item Is one round of learning from the model's own successes the right next test?
          \item Should we first finish the new-task evaluation, begin learning from the model's
            own successes, or improve the scores needed for later reward-based training?
        \end{itemize}
      \end{block}
    \end{column}
  \end{columns}

  \vspace{0.6cm}
  \begin{beamercolorbox}[wd=\linewidth,sep=1em,rounded=true]{block body}
    \centering
    \large
    \textbf{Preliminary takeaway}\par
    \vspace{0.35em}
    Early tests suggest that training from examples can improve how a model works inside an RLM.\\
    We now need to show improvement on genuinely new tasks---then ask whether the model can learn
    from its own successful work.
  \end{beamercolorbox}
