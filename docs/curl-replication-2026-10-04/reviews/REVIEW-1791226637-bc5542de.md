# The fresh control reverses the matching advantage

The new no-matching model scored **823.97**, compared with **668.22** for
smaller-update CURL and **280.41** for original CURL on training seed 234.
These are fixed 100k-step endpoints on cartpole swingup, each averaged over
the same ten test starts. This is the first completed three-way comparison
in the added cohort, not its final average.

Original CURL minus no matching is -543.56 reward points. Smaller-update CURL
minus no matching is -155.75; smaller minus original is +387.81. Looking only
at the last difference would miss that neither matching rule beat the control.
Both had beaten no matching on all three original seeds. The reversal weakens
a dependable early-benefit claim without establishing general harm. Different
policies collect different experience, so it does not identify a direct
encoder mechanism. Wrong-target harm in earlier experiments remains a separate
result; it is not evidence that correct matching must improve task performance.
