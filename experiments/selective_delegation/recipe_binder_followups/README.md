These files back up the frozen follow-up wrappers. The accepted jobs execute
their external copies, not these working-copy paths. Plans pin source paths and
content; do not substitute these files into a live or completed run.

External root: `/project/alex_phd/runs/rlm-research-r4/sidecars/selective-delegation-20260921`.
Source: `source-textcraft-recipe-binder-followups-001`, importing unchanged
`source-textcraft-recipe-binder-003` through the queue's explicit PYTHONPATH.

Accepted queue025 waits for the first world47 pilot's scientific release, then:

1. Tests the second trained public model on world47, reusing its completed baseline.
2. Runs the previously prepared original/public comparison on world48 and audits it.
3. Tests the first public model with ingredient binding on world48 and compares
   it with that authenticated baseline.

Each new binder arm has16 episodes and a30-minute collection cap. The old
baseline arms retain their45-minute caps. Every arm shares the original
per-episode limits. Completed outcomes are not rerolled. These follow-up choices
were fixed before inspecting the first pilot's success totals.

The wrappers check model, world and source identity through the frozen builder.
Pilot actions are independently replayed from raw model replies and prior
public recipe observations. The unmodified baseline is taken from its own
completed native audit, not replayed through the modified execution interface.

This is automatic execution assistance, not a learned planner. The model's
target item and quantity are unchanged. Unknown recipes, ambiguous recipes and
non-divisible quantities are not repaired. Any incomplete outcomes stay unknown.
The exact baselines, paths, commands and source hashes are in
`INDEPENDENT-TRAINING-QUEUE-025.json`; do not start duplicate collectors.
