## Primary literature and one conditional alternative

- **DAPO**, version 2, May 2025, filters uniform-reward groups and oversamples
  informative groups. This establishes the zero-contrast issue, not a direct way
  to teach an all-failure goal. Count resampling costs. [Section 3.2](https://arxiv.org/html/2503.14476v2).
- **AdaBack**, version 2, March 2026, uses reference-solution prefixes and adjusts
  their revealed portion using rewards. It also trains on unassisted inputs and
  reports limitations on familiar tasks. Prefix curricula are established prior
  art, not this campaign's invention. [Section 2.1](https://arxiv.org/html/2506.18110v2).
- **SCRL**, May 2026, uses verified subproblems, within-subproblem reward
  comparisons, corresponding answer-span credit, and consecutive progress. It
  mixes original/curriculum problems. Our inference: rewarding arbitrary crafts
  would not reproduce this method, especially with shared consumable inventory.
  [Section 3.2](https://arxiv.org/html/2605.22074v1).

A distinct later comparison is **public-prefix-start RL versus ordinary-start
RL**. Freeze a prefix halfway through each qualified clean A teacher trajectory's
craft actions. Preserve the original inventory baseline, full history and charged
budget. From the same warm model, sample four continuations per goal; credit only
sampled suffix tokens using the unchanged terminal-reward objective and take one
update. Evaluate warm and both fixed endpoints from ordinary starts on identical
A seeds. Never use B to choose a prefix, threshold or endpoint.

This changes the exploration starting state, unlike error penalties, compression
or extra SFT. It tests a fixed curriculum, not AdaBack's full adaptive method.
Exact seeds, prefix manifests and descriptors must be frozen before implementation.
Expected single-A100 work: one 32-attempt suffix collection, one LoRA update, three
16-attempt readouts; roughly 3–4.5 hours, provisional six-hour cap. These are
estimates, not an accepted job. Promotion requires more contrast (for example,
five mixed groups including two previously flat goals) **and** improvement from
ordinary starts. Retire this configuration if only assisted suffixes improve or
rewards remain flat. A one-step null does not refute curriculum learning generally.
