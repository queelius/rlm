# Fresh TextCraft base control

The completed base control strengthens the conclusion that the public-information teacher package
is better than the frozen base on this fixed fresh16 panel. The root goals were fresh relative to
local SFT selection, but share a recipe world and prerequisites; three were TRAIN intermediates.
Moreover, this base control was planned after the teacher result, so it is exploratory evidence,
not untouched confirmation. It does not identify why: the package changes training data/history,
and the base has a much larger serialization/context failure burden.

## Primary paired result

All three arms completed all 16 root tasks × two seeds, with no unavailable slots or failed native
calls. Successes were base 6/32, old privileged-teacher package 1/32, and public-information
teacher package 15/32. Public versus base has 10 paired wins, one loss, and 21 ties: +28.125
points with a 16-root cluster-bootstrap 95% interval of **[+12.5, +46.875]** points. The older
privileged package versus base is -15.625 points (one win, six losses; CI [-37.5, +3.125]), while
the already reported public versus privileged comparison is 14 wins, zero losses, +43.75 points
(CI [+25, +62.5]). The two samples per root are retained together in these intervals; 32 episodes
are not treated as independent tasks.

The base/public comparison is still an exposed, one-recipe-world evaluation, not a fresh semantic
generalization claim or a decomposition/recursion result. There are no child nodes in any arm.

## A major quality/format qualification

| Native metric | Base | Old privileged | Public |
|---|---:|---:|---:|
| Calls | 1,298 | 1,340 | 1,206 |
| Completion tokens | 95,023 | 29,700 | 37,486 |
| Summed native-service seconds | 4,145.64 | 2,559.05 | 3,109.47 |
| Invalid JSON/schema | 179 | 14 | 2 |
| Context-cap episodes | 20 | 2 | 3 |
| Native action errors | 505 | 119 | 550 |

The base's long outputs, 179 schema failures, and 20 context caps are plausible direct causes of
some base losses. Therefore this is not evidence that root-first querying alone caused the public
gain. Conversely, all 550 public native action errors are craft actions—not parser errors: 220
insufficient-inventory, 216 extra-ingredient, 68 missing-required-ingredient, 35 wrong-amount,
one no-recipe, and 10 other craft feedbacks. Public behavior makes progress to executable craft
decisions but still has substantial feasibility/quantity mistakes.

The base audit reports 102 root calls after the target quantity had already been reached, versus
15 for public. However, all such calls occurred in successful episodes: among the 26 failed base
episodes and 17 failed public episodes, **zero** had `root_calls_after_quantity_met > 0`. This
does not establish a stopping failure as the cause of base losses or license a hypothetical rescue;
it only rules out that particular saved-trace explanation for the failed slots.

## Depth and exposure diagnostics

The same completed slots give the following descriptive depth breakdown (successes / slots):

| Max recipe depth | Base | Old privileged | Public |
|---|---:|---:|---:|
| 2 | 4/8 | 1/8 | 7/8 |
| 3 | 2/8 | 0/8 | 5/8 |
| 4 | 0/16 | 0/16 | 3/16 |

Depth four remains the limiting regime even for public teacher. The predeclared exact-identifier
scope stays supplemental: excluding the three roots whose final identifiers occurred as training
intermediates, base/old/public are **3/26, 1/26, and 11/26**. Public versus base has eight paired
wins and zero losses on those slots; public versus old has 10 wins and zero losses. This does not
remove shared prerequisite or world exposure, and it does not replace the all-16 primary estimate.
